# 🦠 Life Game (Conway's Game of Life)

Консольная реализация классического клеточного автомата "Игра Жизнь" Джона Конвея на современном C++. Проект демонстрирует правильную архитектуру (разделение модели и представления), работу с памятью, неблокирующий ввод-вывод и собственную систему сохранения паттернов.

## ✨ Особенности

- **Архитектура**: Четкое разделение на классы `Field` (логика и данные) и `Game` (отрисовка и управление).
- **Производительность**: Использование плоского `std::vector` для кэш-френдли доступа к памяти и `std::swap` для мгновенной смены поколений.
- **Режимы границ**: Поддержка классических "мертвых краев" (Bounded) и тороидального поля (Toroidal), где края замыкаются сами на себя.
- **Авто-режим**: Плавная анимация с возможностью интерактивного управления на лету без блокировки консоли.
- **Собственный формат файлов**: Загрузка и сохранение паттернов в уникальном формате `.lfgm` (Life Form Game Map).

## 🚀 Как собрать и запустить

1. Убедитесь, что у вас установлен **Visual Studio 2026** (или новее) с поддержкой C++17/20.
2. Откройте файл решения `LifeGame.slnx`.
3. Нажмите `Ctrl + F5` (Запуск без отладки) или соберите проект и запустите `.exe` файл из папки `Release`.

## 🎮 Управление

### Ручной режим
| Клавиша | Действие |
|---------|----------|
| `Enter` | Следующее поколение |
| `a`     | Включить автоматический режим (Auto-play) |
| `r`     | Случайное заполнение поля (25% живых клеток) |
| `g`     | Загрузить паттерн "Глайдер" (Glider) |
| `b`     | Загрузить паттерн "Мигалка" (Blinker) |
| `c`     | Очистить поле |
| `l`     | Загрузить паттерн из файла `.lfgm` |
| `s`     | Сохранить текущее поле в файл `.lfgm` |
| `1`     | Сбросить в режим "Мертвые края" + рандом |
| `2`     | Сбросить в режим "Тор" + рандом |
| `q`     | Выход из программы |

### Автоматический режим (Auto-play)
| Клавиша | Действие |
|---------|----------|
| `Space` / `p` | Пауза (возврат в ручной режим) |
| `r`     | Мгновенная перегенерация поля на лету |
| `c`     | Мгновенная очистка поля на лету |
| `Esc` / `q` | Выход из программы |

## 📂 Формат файлов `.lfgm`

Простой текстовый формат для хранения паттернов. 
- Символы `O`, `#` или `*` обозначают **живую** клетку.
- Символы `.` или пробел обозначают **мертвую** клетку.
- Строки, начинающиеся с `#`, считаются комментариями и игнорируются.

**Пример (`glider.lfgm`):**
```text
# Мой первый глайдер
.O.
..O
OOO
```
## 💻 Системные требования

- **Операционная система:** Windows 10 (версия 1703 и новее) или Windows 11
- **Архитектура:** 64-bit (x64)
- **Дополнительные компоненты:** Не требуются (программа полностью автономна)

*Примечание: Программа использует ANSI escape-последовательности для отрисовки интерфейса. На Windows 10 версии 1703 и новее поддержка включена по умолчанию. На более старых версиях Windows цвета могут не отображаться.*
